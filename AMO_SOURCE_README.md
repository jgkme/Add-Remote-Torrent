# Source code for AMO reviewers (Firefox)

This archive is the **readable source** for Add Remote Torrent. The public listing package is produced by webpack (bundle + minify) and therefore requires this source submission per [Mozilla source code submission](https://extensionworkshop.com/documentation/publish/source-code-submission/).

Repository: https://github.com/jgkme/Add-Remote-Torrent  
Extension ID (Gecko): `add-remote-torrent@jgkme`  
Version in this tree: see `package.json` / `manifest.json`

---

## Build environment

| Item | Requirement |
|------|-------------|
| OS | Linux, macOS, or Windows (Linux recommended). Reviewer default Ubuntu is fine. |
| Runtime | **[Bun](https://bun.sh) 1.3.14** (see `packageManager` in `package.json`) |
| Node | Not required if using Bun. Bun runs the webpack CLI. |
| Disk / RAM | A few hundred MB free is enough for `node_modules` + `dist` |
| Network | Needed once for `bun install` (downloads npm packages) |

This project is developed and released with **Bun**, not npm. Please use Bun so the lockfile (`bun.lock`) is respected and the build matches the uploaded XPI/zip.

### Install Bun (required)

```bash
curl -fsSL https://bun.sh/install | bash
# ensure bun is on PATH, then:
bun --version   # expect 1.3.x (1.3.14 used for release builds)
```

Official install docs: https://bun.sh/docs/installation

## Step-by-step: reproduce the Firefox add-on

From the root of this source tree (folder that contains `package.json`):

```bash
bun install
bun run build:firefox
```

That is the full build. The npm script `build:firefox` runs:

1. `webpack --mode production --env browser=firefox`
2. `node scripts/verify-dist-background.js`
3. `node scripts/zip-firefox.js`

Or run the helper script (same steps):

```bash
chmod +x scripts/amo-build-firefox.sh
./scripts/amo-build-firefox.sh
```

### Output to compare with the AMO upload

| Path | Contents |
|------|----------|
| `dist/` | Unpacked extension (load this folder / compare to unzipped listing zip) |
| `add-remote-torrent-vX.Y.Z-firefox.zip` | Same files as submitted to AMO (version from `package.json`) |

Firefox-specific webpack transforms (must match the listing package):

- `background.service_worker` → `background.scripts`
- Strip Chromium-only `offscreen` permission and offscreen assets
- Add `clipboardRead`
- Keep `browser_specific_settings.gecko` (id, `strict_min_version`, `data_collection_permissions`)

### Diff tip for reviewers

```bash
# After build:
unzip -d /tmp/art-amo add-remote-torrent-v*-firefox.zip
diff -ru dist /tmp/art-amo
# Expect no meaningful differences (timestamps may differ inside zip metadata only).
```

## What is machine-generated vs source

**Source (human-edited, in this archive):** `background.js`, `options/`, `popup/`, `api_handlers/`, `manifest.json`, HTML/CSS sources, etc.

**Generated by the build (in `dist/` / listing zip only):** webpack bundles, minified JS, compiled Tailwind CSS (`css/tailwind.css`).

Open-source third-party libraries are pulled via `bun install` from the registry (see `package.json` / `bun.lock`). They are not vendored as pre-minified app code in this archive.

## Tools used in the build (all open source, local)

- Bun 1.3.14 — package install + script runner  
- webpack 5 + webpack-cli — bundling  
- babel-loader / @babel/preset-env — JS transpile for the bundle  
- terser-webpack-plugin — minify  
- postcss / tailwindcss / @tailwindcss/postcss — CSS  
- zip-a-folder — create the firefox zip  

No web-based or commercial obfuscators are used. Code is minified for size, not obfuscated.
